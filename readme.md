# AI Student Study Assistant

## Project Topic
AI Student Study Assistant – An AI-powered chatbot designed to help students understand Artificial Intelligence, Machine Learning, Data Structures and Algorithms, and Programming concepts.

## Project Description
The AI Student Study Assistant is a Python-based chatbot that uses the Groq API to generate answers to students' questions. It provides explanations of technical concepts through a simple and interactive web interface.

## Objectives
- Help students understand technical subjects.
- Provide quick answers to academic questions.
- Make learning easier through an interactive chatbot.
- Demonstrate the practical application of Artificial Intelligence.

## Technologies Used
- Python
- Flask
- Groq API
- HTML
- CSS
- JavaScript

## Features
- Interactive chatbot interface.
- AI-generated responses.
- Answers questions related to AI, ML, DSA and Programming.
- Web-based user interface.
- Real-time communication with the AI model.

## Project Structure
- `app.py` – Flask web application.
- `assistant.py` – AI assistant logic.
- `templates/index.html` – Frontend HTML.
- `static/style.css` – Frontend styling.
- `static/script.js` – Frontend interactions.
- `.env` – Stores API key securely (not uploaded to GitHub).

## How to Run the Project

1. Install Python.
2. Install required packages:

```bash
pip install flask groq python-dotenv
```

3. Create a `.env` file and add your Groq API key:

```text
GROQ_API_KEY=your_api_key_here
```

4. Run the application:

```bash
python app.py
```

5. Open the browser and visit:

`http://127.0.0.1:5000`
